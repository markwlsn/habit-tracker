# Tempo Privacy Notice — local testing version 2026-09-01

This notice is for the Tempo Habit Tracker local-testing release. It is a product notice, not legal advice. Before a public release, replace the controller details, contact address, and retention schedule below and have the document reviewed for the operating organization.

## Data collected

Tempo collects the username, name, age, email address, Philippine mobile number, account authentication data, habits, completion logs, and consent timestamp/version that a user supplies while using the service. Passwords are handled by Supabase Auth and are not visible to Tempo.

## Purpose and scope

The data is used to create and secure an account, provide habit tracking, calculate progress and streaks, respond to support requests, and meet lawful obligations. The local-release mobile number is not used for marketing or disclosed for advertising.

## Processing and recipients

Data is processed by the Tempo Express API and the configured Supabase service. Habit and log data is protected by authenticated API access and database row-level security. Tempo does not intentionally collect sensitive personal information; do not enter health, financial, government-ID, or third-party personal data in habit fields.

## Retention and rights

Account data is retained while an account is active. A user may request access, correction, deletion, or withdrawal of consent. A deletion request may end access to the service; some data may be retained only where required by law. Contact the controller to exercise these rights.
